# 🌐 Wireframe — Tecnologias Web

Este projeto foi desenvolvido como parte da disciplina **Tecnologias Web** do curso de **Bacharelado em Sistemas de Informação**, com o objetivo de aplicar os fundamentos de **HTML** e **CSS** na criação de uma página web estruturada, sem o uso de frameworks ou bibliotecas externas.

---

## 🧩 Objetivo

O projeto tem como proposta **simular o wireframe de uma página institucional**, aplicando conceitos essenciais de marcação e estilização, como:

* Estruturação semântica em **HTML5**;
* Uso adequado de **tags estruturais** (`header`, `main`, `section`, `article`, `footer`);
* Aplicação de **CSS3** para layout, cores, tipografia e espaçamento;
* Desenvolvimento de uma interface limpa, responsiva e intuitiva;
* Organização do conteúdo em seções temáticas (módulos, planos, equipe, contato).

---

## 🧱 Estrutura do Projeto

```bash
/
├── index.html        # Página principal do projeto
├── style.css         # Folha de estilo responsável pelo layout e cores
└── assets/           # Pasta contendo as imagens e ícones utilizados
```

---

## 💻 Tecnologias Utilizadas

* **HTML5** — para a estruturação da página;
* **CSS3** — para estilização, layout e responsividade;
* **VS Code** — editor de código utilizado;
* **Git/GitHub** — versionamento e publicação.

---

## 🎨 Descrição das Seções

### 🔹 Cabeçalho (`header`)

Contém o logotipo e o menu de navegação principal, com links para as seções internas da página.

### 🔹 Seção Inicial (`#inicio`)

Apresenta uma mensagem de boas-vindas e o título principal do projeto, acompanhados por uma imagem ilustrativa.

### 🔹 Módulos do Curso (`#modulos`)

Lista de tópicos introdutórios sobre HTML e CSS, distribuídos em um layout de grade.

### 🔹 Planos (`#planos`)

Apresenta diferentes planos de acesso ao conteúdo, com variações de preço e benefícios.

### 🔹 Right Path (`#right_path`)

Seção motivacional que reforça o aprendizado e incentiva o acesso ao curso.

### 🔹 Nosso Time (`#nosso_time`)

Apresenta os integrantes da equipe com nome, cargo e breve descrição.

### 🔹 Rodapé (`footer`)

Inclui informações institucionais, links adicionais e ícones de redes sociais.
